# 学习通任务查询

独立 AstrBot 插件，注册 `/任务状态 [页码]`（每页 5 条）。仅现有 AstrBot
管理员可用。普通消息不会触发查询，不注册定时推送、主动消息或课程控制。
命令自动进入 AstrBot 的插件指令注册表，不加入 OJ 的 `/帮助` 列表。

University Helper 每 5 秒生成单个管理用户的脱敏快照，AstrBot 仅挂载该
专用目录为只读。插件不读取业务数据库、账号密码、JWT 或 QQ 网关 token，
也不需要添加网络连接。超过 30 秒未更新或文件异常时回复状态源不可用，
不会把旧快照当作当前状态。详情以网页工作台和平台实际进度为准。

配置 `status_file` 指向只读挂载的 `status.json`。后端导出需配置
`CHAOXING_STATUS_EXPORT_DIR`、`CHAOXING_STATUS_OWNER_FILE`；owner 文件明确指定
允许导出的管理用户 ID，不自动扩大至后来新增的管理用户。

群静默守卫必须精确放行 `任务状态`。这只允许指令进入后续处理，
不会绕过 AstrBot 的管理员权限或插件启用范围。已有官方 QQ 按钮菜单属于
另一个通道，本插件不修改这些菜单。SnowLuma 使用文本 `/任务状态` 指令。
