# WE Learn 班级任务

工作台的账号面板读取课程后，可以切换“课程课节”和“班级任务”。两种范围分别选择，可在同一账号任务中执行；“全选全部课程与课节”仍只选择课节，不隐式加入班级测试。

班级任务从本人当前课程、班级的官方任务列表读取，展示类型、开始/截止时间、平台状态和成绩。未开放、已截止及未知状态不自动进入；口语、作文、打卡、资料等当前展示为需人工处理（已有成绩或已读仍显示平台已完成），不将课件录音实验用于班级口语作业。

只有当前可进入的普通班级测试可以选择。批量启动前还需勾选“允许开始所选班级测试”，并允许自动提交。进入测试可能启动平台计时；本地停止、预算耗尽或遇到不支持题型都不会暂停平台计时。程序不会自动定时等待开放、重考、补考或重新提交。

执行前重新读取官方列表。已提交或已有成绩的任务跳过，未开放或已关闭的任务不进入；不存在的任务要求重新选择，不扩大原范围。测试仅从平台明确给出的普通入口进入，不执行接口返回的 JavaScript，也不接受客户端提供的 URL 或真实 taskid。

初版适配经典测试页面的普通单选、多选、单空填空、单个下拉框及简答，保留阅读材料与完整选项顺序。逐分部预检完成后才查答案，答案全部取得后才填写；填写后再次检查所有分部，然后最多一次原生交卷。听力没有文字材料、图片、排序/连线及不认识的控件转人工；验证码、人脸、监考、口令等不自动处理。页面格式与切换不明确时停止，不根据不存在的提交按钮推断完成。

答案通过既有英语缓存/可选 AI 私有管道取得，浏览器不接收服务器 Key。不接第三方题库，不改变 LocalCache → AI、GO/言溪排除、账号/章节并发或现有费用控制。尝试交卷后必须重新读取本人班级任务列表确认已提交/已有成绩；状态未确认提示去官网核对，不自动重试。任务历史、停止、账号锁和重启仍复用工作台；重启保留精确课程、任务类型和任务集合。

## 验证范围

2026-11-05 对指定账号课程只读核实了 gettasklist 的字段、类型、开放时间、成绩以及页面声明的测试入口。该账号当时没有可开始的班级测试：两份尚未开放，另一份已有成绩并结束；因此未开始任何真实测试，也不能称该教材已经完成端到端验收。经典测试填写/多分部/提交与回读使用隔离的模拟页面及响应验证。遇到新的 WE Test 页面结构仍可能需要后续适配。

列表使用目标课程官方页面声明的 `/ajax/task.aspx?action=gettasklist`，与课节 `courseunits/scoLeaves` 区分。缺失入口的任务使用课程内稳定的名称/类型/日期摘要标识，绝不猜测 taskid。社区的 Cookie 上传、无限听力、分数/完成状态改写等实现不在本适配中。
