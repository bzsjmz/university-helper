# 学习通平台成绩核验与章节复习

任务点处理完成与课程综合成绩分开验收。新任务默认读取所选课程的考核权重、平台实得分及可识别的章节次数门槛，在任务详情和控制台显示核验结果。默认参考及格线为 60，可以调整；教师的实际考核要求仍须单独核对。

## 章节学习次数

课程设置了正的章节次数权重且尚未满分时，默认尝试复习所选课程中平台已确认完成的章节。通过原生课程入口和章节页面浏览，让页面自身执行访问脚本，不构造或重放统计接口。任务点 HTTP 处理、视频完成和章节访问计分是不同指标。

每门课使用自身规则。某课的“120 次满分”不能套用到其他课程。页面复习次数只是本地执行数，不能当作平台有效次数；是否满分以平台成绩读回为准。平台后台去重、频率限制和统计缓存规则尚未完全确认。每页约 30 秒停留是应用设置，并非已证明的平台最低计数时长。

默认仅对整课章节任务补充复习。选了章节终点时保持原范围，不扩展为整课次数复习；仅做课程作业或考试的任务不启动复习浏览器。旧任务重新启动且配置中没有此开关时保持关闭，新任务可以在配置中取消。

复习受单轮 240 页、约两小时执行预算限制；统计未更新时有界等待，持续未确认会停止并提示核对。并发任务共享一个原生复习浏览器名额，原有账号、章节并发设置不变。暂停后不发出下一条复习指令，已发出的当前页面可能完成加载；停止会退出该任务的浏览器进程并清理临时目录。

## 核验与任务状态

平台格式不支持、权重合计不符、重复分数冲突或分项与总分不一致时，显示“未核验”，不猜测分数。未知次数门槛不自动浏览。验证码、登录失效或浏览器不可用时提示人工核对。

成绩未达到参考线或章节次数尚未确认，不会单独将任务改为失败，以免触发整任务重试、重复作业或重复 AI 费用。所选章节、作业或考试本身的执行失败仍按原有规则报告。

本功能不补齐综合成绩中的“阅读”时长，不重做已提交作业或考试，也不改变题库、模型、思考或输出长度的全局配置。选择课程作业、考试仍使用原有独立范围开关。

## 接口与隔离

`CourseStartRequest` 新增 `verify_grades`、`review_chapter_visits`（新请求默认 `true`）和 `passing_score`（默认 60，范围 0–100）。核验结果存放在任务的 `progress.grade_results`，当前复习状态为 `progress.visit_review`。

原生复习在独立子进程中运行，通过私有管道传递当前账号的必要会话。浏览器保持沙箱，使用项目私有临时目录，退出清理；不输出完整入口链接、Cookie 或日志签名。网络只允许学习通 HTTPS GET/HEAD 资源，阻止作业提交、考试入口和外部域名。平台变化导致无法完成导航时返回未确认提示，不降级为重放统计接口。
