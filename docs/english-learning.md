# 英语平台试用（WE Learn / U校园 AI版）

入口：导航「英语平台试用」，路径 `/english-learning`。接口位于
`/api/v1/english-learning`，沿用当前管理用户认证并隔离会话/任务。
已通过离线合成页面、模拟请求和实际 Chromium 沙箱/表单保存验证；尚未通过真实课程验证。

## 自动答题与作业

1. 选择平台并输入账号密码；完成平台验证码后，选择课程并设置范围起点、终点。
2. 选择「自动答题／作业（所选范围）」。默认每节预算 300 秒，可设 30–1800 秒。
3. WE Learn 默认先读课件自带答案，再查缓存；「课件与缓存均未命中时使用服务器 AI」
   可取消以只使用免费来源。U校园 AI版仍沿用缓存优先。启用 AI 后的
   真实任务可能收费，测试不会调用真实付费接口。
4. 默认尝试保存。只有单独勾选自动提交，且全页题目都受支持、答案完整、
   填写后复核一致，才点击所选练习/作业页面的原生提交按钮。
5. 仅有新的平台成功提示时记录已保存/已提交；点击后结果不明会提示官网核对，
   不自动重试，不自动重做。部分平台自动保存没有可识别回执时也不会冒称保存成功。

支持标准 radio 单选、checkbox 多选、文本填空、单个 select 的下拉选词及
textarea 简答/翻译。题目按 DOM 顺序处理，选项顺序严格保留；相同选项文本、
一个容器中混有多个选择组、特殊编辑器、多个混合控件无法明确对应时转人工。
图片题、缺少文本的听力、录音/口语题、验证码、人脸、监考、未开放或过期内容
不自动处理。按所选范围的目录顺序逐节处理各内容当前页，不自动进入考试或重考。范围起点与终点相同表示单节；预算按每节计算。停止后不会进入下一节，单节不支持会记录并继续后续已选内容。
独立的班级作业列表/特殊作业页面没有伪造适配；只有符合支持表单的普通课程
练习/作业能够处理，其他页面须提供脱敏结构样例后再适配。

WE Learn 在选中小节后通过原生 StudyCourse 页面读取和填写表单，不构造 100% 分数、
正确率或 completed 数据。对话填空从相应控件的隐藏 `data-itemtype=result` 读取答案，补全邻近题干；支持原生点击选项、`data-controltype=submit` 与唯一 `.cmd_submit` 确认。视频不强制播放；没有文本或课件标答的听力仍交人工。
U校园 AI版从官方 `getHomeCourseListByStudent` 读取已开通教程，使用当前登录 JWT，不自签令牌；通过真实课程卡片与目录打开内容，执行时重新核对名称。旧 `unipus` API 平台值与老版 `courseCatalog` 网址不再接受。
不移植参考项目自签 JWT、随机答案、盲目点击最后按钮、空答案强行提交或自动重做。

任务显示题目数、有答案数、已填数、缺失数、不支持控件数、保存/提交回执数和未确认数。
AI作答数是使用 AI 结果的题目数，不是 HTTP 尝试数或计费请求数。实际 API 用量继续
由既有 api_usage 遥测记录，缺失 usage 不推算为零。

## WE Learn 课件答案优先

账号密码登录后，后台浏览器用该账号的短期登录会话打开所选课程，能读取页面和 iframe
中的 DOM，以及页面已加载的资源；用户不需要打开 F12 或手工导出数据。
只处理可见课件 iframe，跳过预加载隐藏页，页面切换后停止后续答题。
优先级为当前课件明确标答 → 已验证课件答案缓存 → 原有缓存 → 用户启用的 AI。
命中课件标答不初始化 AI provider，不调用付费接口，关闭 AI 时仍可使用。

当前支持两类明确绑定的来源：

- 题目/原生控件/关联选项标签上的 `data-solution`。填空按控件关联、选项按唯一
  文本或明确 value/ID 对应，不把不明的 A/B 字母或数字当成选项位置；多空不靠序号硬配。
  空属性仅在能唯一关联到某个选项时作为该选项的标记。多种来源冲突、备选答案分隔串、
  不明结构或开放题占位文本均不采用，不把学生已填值、普通 `answer` 字段当标答。
- 当前课件页面自己加载的有界 XML 响应，识别 QTI 样式 `correctResponse`。必须同时
  匹配题目 ID、题干、response identifier；选择题还核对完整选项 ID 和文本，多空逐个
  对应 response identifier。只观察当前 iframe/文档的 HTTPS sflep.com 请求，最多12项、
  单项512KB、合计2MB，拒绝 DTD/实体；不枚举 manifest，不拼接或请求其他章节答案。
  未声明长度、无法明确关联或尚不支持的课件资源视为未命中。

原生标答写入独立 `english-native-v1` 缓存，按平台/课程/题干/上下文/题型/空数/完整
选项顺序隔离，与模型或 endpoint 无关；原有 AI 缓存范围及换序校验不变。
界面分别统计“课件答案”“缓存”“AI作答”，均为使用来源的题目数，不等于计费请求数。
不支持的自定义控件会阻止全页调用 AI、填写和提交，避免遗漏题目后仍自动提交。
保存/提交仍沿用原生控件读回复核与新回执确认，读取到答案不等于作业已提交。

此为独立实现的 DOM/QTI 适配。公开项目说明及字段用法参考
[WELearnHelper](https://github.com/SSmJaE/WELearnHelper) 和
[其发布源码](https://greasyfork.org/sk/scripts/398601-welearn%E7%BD%91%E8%AF%BE%E5%8A%A9%E6%89%8B/code)，
未复制或运行其 GPL 脚本、远程题库、分数/进度改写或随机作答代码。
离线合成页面与 XML 验证不保证用户实际教材均采用这些格式；无法明确命中的内容继续
回退缓存/已启用的 AI，特殊控件或缺答案仍提示人工处理。

## 与之前答题逻辑的复用

- 使用现有 CacheDAO 的进程共享缓存、同题请求锁和当前等待者失败复用。
- 英语缓存使用独立命名空间，包含平台、课程、题干、上下文、题型、空数、完整
  有序选项和服务器模型/endpoint；不会用旧选项字母绕过换序校验。
- 使用现有 AI provider 的服务器配置、DeepSeek 双 Key、有界重试、HTTP 200
  空/坏响应不再生成、token 限制、超时和 usage 统计。
- 每个新任务初始化自己的 provider，读取当前服务器 Key；英语任务共享请求信号量，
  默认最多 3 个在途请求。没有恢复学习通账号或章节并发上限。
- 使用现有 question/job 控制作用域；单题默认 120 秒，整体另受所选答题预算限制。
  同步 HTTP 无法精确强杀，取消会阻止后续取题和提交；在途网络最多等其有界 timeout。
- AI 在后端父进程执行，浏览器子进程仅通过私有管道传题/接收答案，不接收服务器 Key、
  数据库或 JWT 环境变量。未走会输出原始题目/答案日志的 Tiku.query 包装层。
- 缓存只接受通过形状和选项校验的答案；这不是正确率保证，AI 可能答错。

## 原限时学习模式

WE Learn 仍可读取课程/开放小节、按实际等待心跳累计时长；原进度、分数和完成状态
保留平台返回值。首次使用小节须先在官网打开以初始化学习数据。
U校园 AI版限时学习打开所选目录内容，不写入伪造时长或完成状态。
本地会话结束不等于平台课程通过，实际时长/进度/成绩须在官网核对。

## 登录信息与隔离

默认直接输入 WE Learn 或U校园 AI版的账号密码，无需复制 Cookie、导出 JSON 或粘贴课程网址。
后台在隔离浏览器中打开平台真实登录页，填入账号密码；图形验证码、动态码和协议确认
由用户在本页的平台画面中完成。画面支持点选、拖动、滚动和键盘输入；程序不识别或破解
验证码、不替用户勾选平台协议。登录成功自动读取课程，无需提供课程目录网址。AI版主页为 `https://uai.unipus.cn/`，使用官方 SSO service 登录。

登录画面会等待页面渲染，并跳过空白弹窗。检测到纯色空白截图时不展示无效验证输入，
而是提示等待或重试；可使用“刷新画面”“重新加载页面”“回到页面顶部”。重新加载
仅以 GET 打开当前平台官网地址，不重放密码表单；平台可能要求重新填写登录信息。

WE Learn 另提供“微信扫码登录”，仅需已在平台官网绑定微信的 WE Learn 账号。
点击后展示本次官网授权二维码，用户用微信扫一扫并在手机确认；程序在同一隔离浏览器
内等待官方回调，成功后直接读取课程，无需填写账号密码或导入 Cookie。二维码过期时
可点击“刷新二维码”，也可取消登录；未绑定账号请先在官网完成绑定，本功能不创建或
自动绑定新账号。U校园不显示该入口。二维码只在所属用户的短期登录窗口展示，不入库、
不写日志。只允许官方微信授权域名以及确需的静态资源/轮询域名，不访问桌面微信本机助手。
等待用户操作时浏览器事件继续执行，确保扫码后的轮询和跳转能完成；若授权返回空白
中转页，保留同一浏览器会话，最多自动重新打开一次原 WE Learn 登录入口来建立课程
会话，不重放含授权码的回调，不自动提交绑定/注册表单。授权返回期间显示连接课程
进度，与尚未加载的空白登录页区分。

密码仅经认证接口和私有 stdin 管道使用，不保存为账号记录。验证浏览器最多保留十分钟，
可随时取消；每个管理用户最多一个待验证窗口，整个后端最多两个待验证窗口，仅限制
登录浏览器，不改变学习通账号/章节并发。窗口同样按管理用户隔离，刷新可找回未结束
的验证。成功/取消时先让浏览器关闭，异常时回收进程组和该登录专属临时目录；截图
只在短期内存/API响应中使用，相关接口禁止缓存，不写截图文件。子进程仍不继承服务器
AI Key、数据库/JWT 环境。真实平台登录结果尚未使用真实账号验证。

“高级：导入已有登录会话”保留兼容入口：WE Learn 接受目标平台请求 Cookie；
U校园 AI版接受仅含 `unipus.cn` cookies 和 `https://uai.unipus.cn`、
`https://ucontent.unipus.cn` origins 的 Playwright storage state，不接收老版课程目录网址。
日常使用账号密码入口即可，不读取本机已有浏览器 profile。

登录信息不写 localStorage、日志、数据库或任务返回值。服务端使用既有 Fernet
辅助工具在短期内存会话中保存，子进程通过 stdin 短暂使用明文，退出即释放副本。
会话一小时过期（执行中延至结束清理），可手动断开；终态任务保留两小时。
任务/登录状态不跨重启恢复，不自动重新启动，不加入学习通账号表或 QQ 快照。
同一试用会话只允许一项操作；重复导入同一真实账号没有跨会话去重，请勿同时运行。
独立低权限宿主管理用户尚未落实。

## 浏览器运行环境与上线

两平台自动答题及 U校园 AI版目录/阅读均需要 Playwright 和 Chromium。WE Learn 的
原课程读取/时长模式只需要 requests。原始上游 app 基础镜像不含浏览器。

可选 `Dockerfile.english` 固定 Playwright 1.63.0，在镜像内安装官方 Chromium
headless shell 和系统依赖，以原 app 用户运行，保留 `chromium_sandbox=True`。
已在禁网、只读根文件系统、UID 10001、cap-drop ALL、no-new-privileges、
512MiB/0.75CPU/192 pids 的容器内验证真实浏览器填写及原生保存回执。
默认 Docker seccomp 在移除全部能力后会拦截沙箱初始化；运行环境需要审核
用户命名空间创建、沙箱内 chroot 及 PID 命名空间 clone 的受限规则。
不得关闭 sandbox、添加宿主能力、使用 seccomp unconfined 或自行提高资源限额。
构建/namespace 与 sandbox 要求参考 <https://playwright.dev/python/docs/docker>。

构建示例（不代表部署授权）：源码目录执行
`docker build -f Dockerfile.english -t university-helper-app-english:trial .`。
专用 dockerignore 只开放后端源码和浏览器依赖清单，排除 runtime/secrets/data/profile。
每个部署环境仍须验证 sandbox 和现有资源预算，核对活动任务并取得上线授权。
合成页面通过不保证真实课程结构兼容；源码与镜像构建成功不代表已部署。
浏览器只允许平台域名的 HTTPS 资源，不授权摄像头/麦克风、不共享 profile 或 Docker
socket；依赖其他 CDN/第三方域名的课程可能无法打开，须明确核对后另做受限适配。

## U校园 5.0 登录入口与扫码回调

U校园入口现为官方 <https://ucloud.unipus.cn/>，登录从该站的 `/sso/login` 发起并返回该站，界面标注“U校园 5.0（AI版）”。官方 5.0 门户公开前端仍将课程 API 发往 `uai.unipus.cn`；保留固定课程接口，认证状态新增仅限 `https://ucloud.unipus.cn` origin，不要求用户复制 Cookie。官方统一认证表单本身可能沿用旧样式，不能仅凭表单外观判断落地平台。匿名页面已确认用户名/密码及协议控件；真实账号的登录和教程仍需验收。

WE Learn 授权回调允许至少五秒处理，不提前 GET 离开回调；页面短暂替换或扫码弹窗关闭后继续查看同一会话的存活官方标签，不重放授权码或提交操作。网络读课程暂时失败继续等待；平台超时、浏览器跳转和 worker 响应超时分别给出固定安全提示，不再全部称为二维码过期，不输出页面网址、异常正文或令牌。真实微信确认后的平台响应尚未使用用户账号复现。

单次 HTTP 等待结束而登录 worker 仍存活时，保留十分钟以内的原登录窗口，下一次轮询只读未完成的回复，不重复写 refresh 或用户操作。U校园5.0 同域 `/sso/` 登录页的验证码、图片和字体保留，仅门户装饰资源作轻量加载。
