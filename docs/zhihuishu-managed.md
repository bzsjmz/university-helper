# 智慧树账号与课程队列

智慧树页面支持保存多个账号、修改备注、更新登录及删除账号。扫码或密码登录后仅保存加密会话，不保存输入的密码；Cookie 不返回前端、不进入浏览器本地存储。所有账号、课程和队列接口均按管理用户隔离。首次从旧版内存会话升级时需要重新登录一次，后续服务重启可恢复保存的登录状态；平台会话过期或身份验证仍需人工登录，不保证永久有效。

选择一个账号后勾选一门或多门课程，也可全选。课程按展示顺序串行执行，可逐门指定截止章节（包含该章）；未指定时学习整课。倍速与普通/AI模式作用于本次所选课程。同一真实智慧树账号仅能有一个活动队列，包括不同管理用户保存的同一账号；不同账号可各自运行。存在任务的账号不能删除或更新登录。

队列支持暂停、继续和停止；停止会协作取消当前课程，等待执行线程退出后才释放账号锁，剩余课程不会启动。课程失败、空视频列表、未知状态或登录失效均停止后续课程。课程开始前重新验证登录与所属范围。服务重启保留队列记录，将活动队列标为 interrupted，不自动学习或重放请求；用户可以重新勾选原范围中的未完成课程，依平台视频进度继续。

此功能沿用原智慧树视频实现。AI模式仅在视频列表附带题目时生成答案，尚未实现答案提交，不主动进入章节测验或考试。程序显示 completed 只是视频任务处理结果，不代表测验已交、课程成绩合格或平台最终验收。

账号和队列使用既有 PostgreSQL / SQLite 存储接口，账号会话通过既有 Fernet 密钥加密；缺少有效加密配置时拒绝保存。公开响应不包含 Cookie、签名课程 secret、账号身份哈希或服务密钥。更换或丢失原 Fernet 密钥会使已存会话无法解密。部署应在所有用户任务及等待队列空闲后执行，并先备份；不能通过重启结束活动课程。
