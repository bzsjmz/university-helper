# 学习通作业与测验

章节测验与课程作业采用不同入口。课程作业兼容官方移动端的
`/mooc-ans/android/mtaskmsgspecial`，以及带或不带 `/mooc-ans` 前缀的
`/work/phone/doHomeWork` 和提交路径；地址仍须匹配固定 HTTPS 主机与路径，
并核对课程、班级及试卷标识。

计算题（题型 7）按文本解答处理。移动端优先从实际题干容器提取内容，
避免将“计算题”等题型标签当成题干。分页试卷须完整读取后才答题。

列表中已过期或未开放的条目单独跳过，不阻断同一列表中其他开放作业。
章节测验页明确显示“已截止，不能作答”等状态时，在字体解码及题库调用前
返回未开放状态，不提交，也不计为章节完成；是否跳过沿用任务的未开放策略。

任务 API 可通过 `course_homework_titles` 精确选择课程作业标题；缺省为处理所有
可执行作业，空列表表示不进入任何作业。选择会随重启配置保存；不匹配的其他
作业不会进入或提交。

加密题目仍要求独立部署有效的 `backend/resource/font_map_table.json`。
仓库不附带字体映射数据；缺失或映射不完整时停止答题，不能将乱码交给 AI。
仅补上文件不会更新已运行进程内的映射，需要在任务空闲时更新后端。
