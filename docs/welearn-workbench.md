# WE Learn 工作台

在导航进入 **WE Learn**（`/welearn`）。U校园继续使用独立的试用入口。WE Learn 仍处于测试阶段，教材、题型与录音实验的兼容范围没有因新增工作台而扩大。

## 日常使用

1. 点击“添加账号”，填写备注，用密码或微信扫码登录。完成平台验证后，服务器核验官方账号身份并加密保存登录会话；不保存平台密码。
2. 每个账号可以读取课程后，选择课程并“读取／刷新课节”，点击“全选本课程课节”，也可逐节勾选。想选择该账号全部已开放内容时，直接点“全选全部课程与课节”。选择不会自动启动任务。
3. 勾选需要启动的账号，或点“全选空闲账号”。批量启动区会列出账号和课节数量；默认完整答案复核后自动提交，课件及缓存未命中时允许 AI，均可关闭。
4. 核对范围和选项后点“确认并启动所选账号”。不同账号独立并发，同一账号的课程与课节按顺序执行。未选择课节和忙碌的账号不会启动，部分账号启动失败会单独显示原因。
5. 查看任务记录和逐节结果。程序读取平台进度，跳过已完成课节；只有平台确认才计为完成。需要人工处理、提交被拒绝和回执未确认会保留真实状态。

录音实验默认关闭，需要明确勾选。它不生成真实、可播放的音频，评分录音为 0 分占位；是否完成仍以平台回读为准。每节至少停留 10 秒，新 AI 查题请求前随机等待 20–40 秒，课件及缓存命中不等待。

## 登录、历史和重新启动

账号记录跨刷新和后端重启保留。平台仍可能让 Cookie 过期，遇到登录失效时点该账号的“更新登录”，使用原账号再次验证。重复登录同一官方 uid 会更新已有账号，不会新增重复记录；更新登录不能将已有记录换成另一个真实账号。

历史记录持久化；执行线程不会跨后端重启恢复。重启中断的记录显示“重启中断”，点“重新启动”会使用账号当前的登录，重新读取目录并保留原先精确课节集合，不自动加入新课节。原课节关闭或删除时要求重新选择，不扩大范围。暂不提供自动定时重试。

停止任务须等待工作进程退出，随后才能更改或删除账号。删除账号会移除登录凭据，保留任务历史和平台学习进度。删除账号后的历史不能重新启动，需重新添加账号、选择范围。每个管理用户最多展示最近 2000 条任务，旧记录不会因两小时内存清理而被删除。

## Agent 部署说明

- 后端入口：`/api/v1/welearn`。所有账号、目录和任务操作都要求管理用户身份，并检查 owner；凭据和内部配置不出现在 API 返回中。
- 首次操作时在实例现有存储中建立 `welearn_accounts`、`welearn_tasks` 表，兼容 PostgreSQL 和本地 SQLite。保留数据库和 `CREDENTIAL_ENCRYPTION_KEY`，同时备份；密钥不变才能解密历史登录。
- 保存前要求 Fernet 加密可用，开发环境的明文回退不能用于保存账号。账号唯一性来自官方页面 uid 的服务端 HMAC，不从用户输入的 Cookie 字段推断身份。
- 多账号复用现有 WE Learn 浏览器工作进程、课件答案、缓存与 AI 链路；未启用其他 HTTP 适配草案或增加 TTS 服务。单个真实账号在不同管理用户下也不能同时启动工作台任务。
- 上线前同时检查已有平台任务、WE Learn 工作台活动任务、英语登录和答题工作进程，空闲时备份，再只更新 app/web。重启会中断活动线程，不能以持久化登录为由宣称执行自动恢复。
- 为 SQLite 隔离测试运行 `backend/tests/unit/test_welearn_workbench.py`；数据库集成检查 `backend/tests/integration/test_welearn_store_db.py` 仅在 `WELEARN_DB_TEST=1` 且 `MAIN_DB_HOST=testdb` 的临时 Postgres 环境中执行。前端交互检查位于 `frontend/src/pages/WelearnWorkbench.test.jsx`。按目标主机规则使用资源受限测试入口，不能连接生产库运行测试。

服务器完整安装与升级流程参见 [Agent 部署手册](AGENT_DEPLOYMENT.md)。
